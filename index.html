GeoCraft is a minimal Android mock-location toolkit for developers and QA teams testing location-aware applications in controlled environments.

↓ Download GeoCraft APKView on GitHub ↗
What it does

Small surface. Useful controls.

Everything you need to set a controlled test location without turning the tool into a cluttered dashboard.

⌖

Target coordinates

Set precise latitude and longitude values and update the active test location.

✦

Quick presets

Jump to useful preset locations such as Hyderabad, Delhi and Mumbai while testing.

◉

Foreground service

Keep the mock location active while moving between apps with Android's foreground-service model.

↗

Floating control

Optional overlay control gives you a compact status and stop action over other apps.

⚙

Android-native

Uses Android's mock-location mechanism rather than attempting to hide injected locations.

⌁

Open source

Inspect the Android implementation, workflows and website directly in the GitHub repository.

Setup

From install to test in minutes.

GeoCraft intentionally keeps the workflow explicit so you know when Android is receiving a mock location.

$ Install GeoCraft
$ Enable Developer Options
$ Select GeoCraft as Mock Location App
$ Choose coordinates
$ Start mock location

// GeoCraft → foreground service → Android LocationManager
1
Install the APKDownload the latest release and install it on your Android device.
2
Choose GeoCraftIn Developer Options, select GeoCraft under the mock-location-app setting.
3
Set a targetEnter coordinates or choose a preset, then apply them.
4
Start testingStart the foreground service and verify the location behaviour in your test app.
